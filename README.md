# Dompeek – Domain Analytics Tool (Frontend)

A modern web app where users can analyze any domain and instantly get WHOIS data, blacklist status, SEO signals, reverse IP lookup, domain age, and AI-generated insights.

---

## ✅ Why I Built This
This was a client-focused project aimed at giving users a simple dashboard to understand the quality and trustworthiness of any domain.  
The frontend provides a clean UI to display analytics, tables, and AI insights pulled from the backend.

---

## 🛠 Tech Stack
- **React.js**
- **Tailwind CSS** for modern UI
- **Axios** for API calls
- **Backend:** Node.js + Express

---

## ✨ Features
- ✅ WHOIS lookup
- ✅ Blacklist check
- ✅ Domain age & expiry details
- ✅ Reverse IP lookup
- ✅ SEO trend indicators
- ✅ AI-generated domain quality score & insights
